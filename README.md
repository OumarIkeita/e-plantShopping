# Paradise Nursery - e-plantShopping

A professional React-Redux application for a digital plant nursery.

## Technical Stack
- **Frontend:** React 19 + Vite
- **State Management:** Redux Toolkit (@reduxjs/toolkit)
- **Styling:** CSS3 (Flexbox & Grid)
- **Deployment:** GitHub Pages (gh-pages)

## Features
- **Dynamic Product Grid:** 30+ air-purifying, aromatic, and medicinal plants.
- **Centralized Cart Logic:** Real-time quantity updates and total cost calculations.
- **Responsive Design:** Optimized for Mobile, Tablet, and Desktop.
- **Provider Pattern:** Global state injection for seamless component communication.
